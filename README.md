# 📚 iLearn.ai – AI-Powered Course Generator

## 🚀 Build & Generate AI-Powered Courses in Seconds!

iLearn.ai is an AI-driven course generator that enables users to create structured, high-quality educational content in just a few clicks. With powerful AI integration, seamless authentication, and an intuitive interface, this full-stack application makes course creation effortless.

---

## 🔥 Key Features

✅ **AI-Generated Courses** – Generate structured courses based on your topic and preferences.
✅ **Step-by-Step Wizard** – Intuitive UI guiding users through the course creation process.
✅ **Authentication & Security** – Clerk integration for secure user management.
✅ **Database Management** – Drizzle ORM ensures seamless database interactions.
✅ **Sleek & Responsive UI** – Designed with TailwindCSS for an elegant and adaptive experience.
✅ **Fast & Scalable** – Built with Next.js for performance and scalability.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TailwindCSS  
- **Backend:** Node.js (API integrations)  
- **Database:** Drizzle ORM (PostgreSQL)  
- **Authentication:** Clerk  
- **AI Model:** Gemini API  

---

## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/yourusername/ilearn-ai.git
cd ilearn-ai
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Set Up Environment Variables
Create a `.env.local` file and add:
```bash
NEXT_PUBLIC_GEMINI_API_KEY=your_api_key
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_key
DATABASE_URL=your_database_url
```

### 4️⃣ Run the Application
```bash
npm run dev
```
The app will be live at [http://localhost:3000](http://localhost:3000) 🎉
