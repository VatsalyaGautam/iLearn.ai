📚 iLearn.ai – AI-Powered Course Generator

🚀 Build & Generate AI-Powered Courses in Seconds!

iLearn.ai is an AI-driven course generator that helps users create structured, high-quality educational content in just a few clicks. Powered by Next.js, React, TailwindCSS, Gemini API, Clerk, and Drizzle, this full-stack application streamlines course creation like never before!

⸻

🔥 Key Features

✅ AI-Generated Courses – Get structured courses based on your topic & preferences.
✅ Step-by-Step Wizard – Intuitive UI guiding users through course creation.
✅ Authentication & Security – Powered by Clerk for secure user management.
✅ Database Management – Drizzle ORM for seamless database interactions.
✅ Beautiful UI – Designed with TailwindCSS for a sleek & responsive interface.

⸻

🛠️ Tech Stack
	•	Frontend: Next.js, React, TailwindCSS
	•	Backend: Node.js (API integrations)
	•	Database: Drizzle ORM (PostgreSQL)
	•	Auth: Clerk
	•	AI Model: Gemini API

⸻

🚀 Getting Started

1️⃣ Clone the Repository

git clone https://github.com/yourusername/ilearn-ai.git
cd ilearn-ai

2️⃣ Install Dependencies

npm install

3️⃣ Set Up Environment Variables

Create a .env.local file and add:

NEXT_PUBLIC_GEMINI_API_KEY=your_api_key
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_key
DATABASE_URL=your_database_url

4️⃣ Run the Application

npm run dev

The app will be live at http://localhost:3000 🎉
